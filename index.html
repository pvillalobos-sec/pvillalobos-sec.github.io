A Python app that pulls live weather data from the NOAA API and turns it into readable visuals. CEIS114

Project #3

IoT Traffic Controller

A six-week project designing and simulating a working traffic light system on an ESP32 microcontroller in the Wokwi virtual environment. Started as a single light and grew into a full system — two lights, a pedestrian crosswalk button, a buzzer, and an LCD display. Hands-on practice in coding, wiring, troubleshooting, and combining hardware with software into a functioning digital device.

ESP32Embedded SystemsWokwi⇩ slides.pptx

End of Course Project

SOHO Network Lab

Designed, configured, and secured a small office/home office (SOHO) network — covering the OSI and TCP/IP models, IP addressing, Class C subnetting, connectivity testing, and wireless security controls like WPA2/WPA3 encryption and MAC filtering. Built a strong foundation covering key concepts from the CompTIA Network+ certification.
